# Logos

Work Manage (W) e Service Manage (S), separados do vetor original e coloridos com `navy` #0B1C35 e `blue` #1B6AF3. Os dois símbolos têm a mesma altura (o S foi reduzido para 81,5 %); a wordmark em MuseoModerno 600 já está em curvas.

- `w-logo.svg` / `s-logo.svg` — logo horizontal colorido (símbolo + nome). O uso padrão.
- `w-logo-stacked.svg` / `s-logo-stacked.svg` — empilhado, para espaços quadrados (avatar, splash, etiqueta).
- `w-mark.svg` / `s-mark.svg` — só o símbolo. Ícone de app, favicon, 16 px.
- Sufixos `-navy`, `-white`, `-blue` — versões 1 cor. `-white` para fundos `navy`, `blue` ou foto; `-navy` para fundos claros fora da paleta; `-blue` quando só o azul está disponível.

Tamanho mínimo: logo 24 px de altura, símbolo 16 px. Área de respiro de 1/4 da altura em volta. Não rotacionar, esticar nem recolorir fora destas versões.
